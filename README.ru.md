## Как я работаю

- **Сначала оценка.** Первым появляется контрольный набор (вопросы, запросы или юнит-тесты); каждое изменение меряется на нём.
- **LLM-судье не верю на слово.** Его оценки идут в паре с более простым сигналом (сходство, юнит-тесты) и служат ранним предупреждением, а не заменой ручной проверки.
- **Статистика, а не «на глаз».** t-тест Уэлча против базовых прогонов, нулевая модель для метрик «устойчивости», несколько seed'ов там, где прогоны шумные.
- **Воспроизводимость.** Зафиксированные seed'ы и версии данных, прерываемые и продолжаемые эксперименты, сырые результаты рядом с итоговыми.
- **Отрицательный результат — тоже результат.** Если гипотеза не подтвердилась, README так и пишет (см. ai-compute-optimizer и embedding-translator).
