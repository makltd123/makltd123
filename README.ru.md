# Фёдор Маковский — AI-разработчик

[English](README.md) | **Русский**

Делаю для бизнеса ИИ-ассистентов по документам компании, ботов поддержки и поиск по смыслу. До запуска замеряю качество на вопросах самого заказчика, а о том, что не сработало, пишу так же открыто, как об удачах.

## Чем занимаюсь

- **Ассистент по базе знаний**: сотрудник спрашивает своими словами и получает ответ со ссылкой на документ.
- **Бот поддержки** для сайта и Telegram: отвечает по вашим правилам, сложное передаёт человеку.
- **Поиск по смыслу** для каталога и сайта: синонимы, опечатки, описание задачи вместо названия товара.
- **ИИ на своём сервере**, когда данные нельзя выпускать из компании: модели сравниваются на ваших задачах до покупки железа.
- **Аудит готового ИИ-бота**: доля верных ответов, типы ошибок и стоимость 1000 ответов на более дешёвой модели.
